`main.ts` (Node 22, standard library only) writes one calming text to
`/output/entry.txt`: a single warm voice speaking to a tired reader, built
around one image — lamplight on a quiet floor — with nothing to prove and
nothing asked of the reader. No network, no randomness, no time reads; the
output is fixed and byte-identical on every run.
